# Product Overview

_updated_at: 2026-02-24_

altpocket は、Pocket 互換の「あとで読む」体験を提供するセルフホスト可能なサービスです。  
ブラウザ拡張・Web UI・モバイル共有導線から URL を保存し、後で一覧・検索・再取得できることを主目的にしています。

## Core Capabilities

- URL 保存時に正規化（canonical URL/hash）して重複登録を抑止する
- タグを正規化して管理し、一覧・検索・タグ絞り込みを一貫して扱う
- 保存と本文取得を分離し、保存は即時応答、本文取得は worker が非同期実行する
- Web UI（SSR）と Chrome Extension から同一 API を利用し、同じデータモデルで操作できる
- Google 認証を基盤に、Web セッション運用と拡張機能向けトークン連携を両立する

## Target Use Cases

- 読書候補 URL を素早く保存し、後で検索して読む
- 収集した記事をタグで分類し、再訪しやすくする
- 取得失敗を許容しつつ、再フェッチで内容を回復できる運用を行う
- 個人または小規模チームで、自前ホスティング前提の read-it-later 基盤を持つ

## Value Proposition

- 保存経路を複数用意しながら、保存先・検索体験・認証を単一サービスで統一できる
- API 応答性（即時保存）と取得品質（非同期本文抽出）を分離した実運用向け設計
- Go + PostgreSQL + Docker Compose を中心とした、理解しやすく移植しやすい構成
